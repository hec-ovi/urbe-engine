# CONTRACT: game (engine inner box)

Purpose: plays the assembled city as a first-person world at street level, at night, from generated data only.

## In
- `?mode=game` on the vite app, with the run described entirely by the URL query:
	- `game`: optional catalog game id. When present, the run is bound to `/out/games/<game>` and loads its [persisted descriptor](persistence/schema/game-state.schema.json). The descriptor restores the exact player foot position, heading, inventory, quest runtime, locations, revision and elapsed play time. A conflicting `out` query is ignored. Without `game`, direct assembled-city play remains session-only.
  - `world` (default `city-urbe-tiny`): atlas sample name, loaded from `/atlas/<world>.json`
  - `out` (default `/out/city-tiny`): the `assemble-city` output directory to read buildings from
    The directory's own `blueprint.json` (the blueprint it was assembled from, named or not) is the world's blueprint; the atlas sample named by `world` is the fallback. An `npc-types.json` in that directory (the naming box's typed set for this world) drives the population's types and names; absent, the simulation's built-in set does.
  - `backend` (`webgpu` default, `webgl`)
  - `hour` (0-23, default 21): world clock start
  - `crowd` (default 200), `cars` (default 18): instance capacity
  - `density` (default 1): the simulation's `params.streetDensity`, the researched share of the population out in public space
  - `stress` (default 0, max 40): debug only, keeps N extra bodies per real street agent walking nearby walk edges to load-test the crowd renderer. They carry no identity of their own and never count towards street density. Off in every normal run.
  - `lanes=debug` paints every lane of the road graph end to end, `lanes=glow` restores the teal emissive centreline strips. Debug only; a normal run gets painted road markings.
  - `quality` (`low` | `medium` | `high` | `ultra`): what the frame is allowed to spend (src/game/look/CONTRACT.md). Unset follows the backend: `high` on WebGPU, `low` on the WebGL2 fallback.
  - `exposure` (default 0.024): the one number the whole look is graded at. Tuning only.
  - `fog` (default 0.0003): street fog density per metre, sky-coloured and untinted, so a distant building fades without changing colour; the first block stays crisp.
  - `off` (comma list of `fog`, `bloom`, `probe`, `haze`, `interiors`): look stages left out of the run, for telling them apart on screen. A tier whose bloom strength is 0 (the `low` tier, and any run with `off=bloom`) runs no emissive target and no blur chain at all. GPU timing queries run only on WebGPU.
- HUD (src/ui/CONTRACT.md): the panels open on J M I X O ? and close on Esc, N and Esc pause; the tab bar is on screen only while paused or while a panel is open; a panel or the chat releases the mouse and owns the keyboard; the settings panel changes fog, exposure and crowd on the spot and reloads the run for a quality tier; the full map is the city as blocks orbiting the player. Both maps show venue state, generated transit routes, bus stops, train stations, subway entrances and the active objective route. Transit lines preserve Connections' authoritative heights on the full map and use their XZ projection on the minimap.
- Atlas blueprint per ../../../atlas/CONTRACT.md.
- Connections document, generated in-process from that blueprint by `connectionsRunner.js`; `signalStateAt` is consumed directly for signal state.
- `<out>/manifest.json` per [../assembly/schema/world-manifest.schema.json](../assembly/schema/world-manifest.schema.json): which blueprint the directory was assembled from, every complete shell in `parcels`, the explicit enterable subset in `interiors`, floor files for exactly that subset, and Connections' post-exterior rooftop span document. It is the only list of buildings, floors and rooftop spans the game reads. A missing, malformed or mismatched manifest fails the run with what to re-run.
- Per `parcels` id, under `<out>/<id>/`: the exterior blueprint and shell GLB. Only an `interiors` id also has `interior/npc.json` and per listed floor `interior/floors/<tag>.json` plus `interior/floors/<tag>.glb`. `WorldSource` hands each floor document to the game with the `glbUrl` of its own GLB and never requests interior files for a closed shell. A blueprint parcel absent from `parcels` is reported as unbuilt, never an error.
- Materials theme database under `/materials/<theme>` per ../../../materials/CONTRACT.md.
- CC0 character, animation and vehicle packs under `/models`, served from `URBE_MODELS_DIR` (default `<home>/models/quaternius`). `npm run install-character-assets` stages the user's Universal Base Characters Source and Universal Animation Library Pro from the workspace resources folder, validates them, then replaces the local model store without putting vendor binaries in git. The install fails unless all six full-body rigs and all 32 age-specific hairstyle and facial-hair rigs match the animation pack's 65-joint skeleton and the required locomotion clips exist. Its format 2 `character-assets.json` records hashes of the original archives and every installed file. `npm run audit-character-assets` verifies those hashes and rigs without changing the store.
- Optional story data under `<out>/quests`: either the complete Quests v0.8.1 `quest-bundle.json` v1.1 and its seven named files, or a standalone `questlines.json` definition array. The complete bundle is validated through [../quest-bundle/CONTRACT.md](../quest-bundle/CONTRACT.md) before any step enters play. A development HTML shell at an optional file path means the file is absent; malformed JSON and other content types fail startup.

## Out
- A walkable city: pointer-lock mouse look, WASD at 1.4 m/s, Shift at 4 m/s, Space to jump and held C to crouch at 0.9 m/s. Standing eye height is 1.7 m and crouched eye height is 1.05 m. W walks along the look direction, A and D strafe left and right of it. Gameplay keys clear on pointer unlock or lost focus, and one physical Space press starts at most one jump.
- `GameApp.tick(delta)`: one deterministic step of clock, physics, agents, interaction and render. The animation loop calls it with real elapsed time; a harness with no display can call it directly.
- HUD under `src/ui`: clock and district, interact prompt, position readout, about line naming every loaded path, NPC panel, pause menu, performance readout. The readout names the live backend, quality tier and render size on its first row the material resolution (`N materials  M unresolved`) and the run's own freezes (`N hitches  M ms worst`, or `no hitch`) on its last two, so a screenshot says which path drew the frame, whether the world's keys all answered, and whether it stalled on the way.
- **Interaction**: E acts on whatever the crosshair is pointing at. Every door, person, physical quest target and authored investigation target in reach is scored by how far off the centre of the screen it sits and the most centred one wins; distance only decides who is in reach at all. An aim too close to call goes to the door, because a person can be looked at squarely and a doorway with somebody standing in it cannot. The prompt always names its target ("E open the door to BAR", "E talk to Clara", "E inspect tyre transfer mark"). R takes the selected target's secondary action, including reading a quest document or collecting inspected portable evidence. While waiting for transit, this selected world target owns E and transit is considered only when there is no world target. While aboard, the ride owns E and keeps the scheduled disembark action selected.
- **Conversation**: every typed line goes to POST `/api/talk` with the person, their current behavior and the simulation time. The quests dialog layers that person's story role over the model selected by `LLM_BASE_URL` and `LLM_MODEL`. What each NPC has been told is remembered for the session. A text-model failure answers "..." and leaves chat usable. Conversation preserves the visible npcId and position, pauses its simulation routine, and walks it back into the current routine on close. Talking to a follower pauses movement without releasing follow control. Player and NPC turns coordinate standing or seated Pro speaking and listening gestures; an NPC reply holds its gesture for 1.8 seconds unless another line or the close action settles it first.
- **Quests**: the world's questlines run on the quests flow runtime against this simulation. Every role is cast at load through the game's own population, and a questline nobody here can play is left out. Talk, goto, pickup, observe, listen, steal, work and delivery use the measured dialogue, place and shared-interactor paths. Rescue acquires exact follow control before progress and releases newly acquired control if the runtime rejects the event; access, hacking and sabotage act only on their bound mission asset and exact interaction anchor. Escort starts the authored follower or leader at its source and completes at the exact destination before routine resume. An active assassination target or transit passenger receives its exact cast body without adding an interaction. Assassination consumes only a measured fatal vehicle contact after the full Source ragdoll accepts it and GameApp resolves that body to its authored npcId. Transportation keeps the exact passenger from its authored parcel, station or stop origin through a measured public-transit ride and onward to the authored destination, then verifies its cargo before completion. Accepted actions enter the deterministic Pro animation lifecycle; rejected actions do not. Completion, inventory, route guidance and catalog persistence share one result path. A saved quest restores its cast, steps, flags, ending and active transportation stage, and the active parcel, station or stop objective routes over Connections `path3`.
- **Investigations**: `quests/investigations.json` may publish version 1.1 authored interior and street scenes. Every scene is bound to exact quest, step, scene, evidence and place ids. The game renders mission-asset assemblies and fitted PBR decals, and loads audited Source bodies in a final Pro death pose without replacing their original textures. E inspects and R collects only after focus, reach, place and physics occlusion checks. Only an accepted scene result emits the exact `investigated` event to its named quest.
- **Saved playthroughs**: leaving a run opened with `game` posts a schema-validated [saveCurrent payload](persistence/schema/save-current-payload.schema.json) before returning to the launcher. It carries the live foot position and heading, merged inventory, restorable main and side-job progress, complete investigation discovery, collection and one-shot transition state, current and discovered locations, cumulative play time, exact simulation and NPC continuity state, world minute and expected revision. A refused save leaves the player on the run and reports the error. Direct assembled-city play performs no persistence request and returns directly to the launcher.

## What the world is made of
- **Ground**: the blueprint's `volumetric.ground` cover. Grade roadway is at y=0; sidewalk, block and open areas are at y=0.12. Each Atlas `highwayStructures` record adds its road deck at the exact elevation profile, split at every profile knot, with the published width and structural depth. Its supports extrude only from the published footprint, bottom and top. The kerb is the blueprint's own `curb` strip where it publishes one, laid at pavement height with a face down to y=-0.06, unbroken through the junction returns; a world published without one has its kerb cut from the pavement edges that meet the road, so no height step can open a gap. The floor is cut open over every station shaft that breaks the surface, and the bedrock slab drops below the deepest volume the city digs, so a stair down is a way down rather than a shape buried under the pavement. One merged mesh per material. Grade roadway uses the neutral, dry `street` asphalt variant because its merged polygons have no common lane axis. Highway decks use the lane-aligned `highway` variant with U across the published width and V along the path, so the 3.5 m tile repeats one pair of wheel tracks per lane. Sidewalk, block and open cover use the neutral `plate` pavement variant, whose joints repeat every 2 m. Horizontal cover UVs stay in world metres at a stable world origin, independent of polygon size and winding. Kerb tops and faces map their 2 x 0.15 m stone along each road-facing edge and across its width, including rotated streets and junction returns.
- **Buildings**: shells come from each parcel's own exterior GLB and merge across the whole city by material key plus an authored `extras.materialVariant` when present, so exact entrance strips stay distinct from ordinary fixtures with the same key. Surfaces without an authored variant keep the building's seeded pattern. The skyline loads once and costs one draw call per resulting material bucket.
- **Interiors, streamed a floor at a time**: a furnished building is tens of megabytes and up to sixty floors, and the player stands on one of them, so neither the building nor the tower above is ever in play. A building within 70 m of the player is opened (its lift shafts registered from its floor documents, a band per floor, all empty) and let go past 95 m. Only the floors within one of the floor the player stands on are fetched, each from its own GLB, nearest building first and the standing floor first, one at a time; those same floors are in the scene and in the physics world, one more above and below stays in memory so a stair landing never refetches, and a floor further away is dropped with its vertex data. So a 35-floor tower costs the three floors around the player: walking up the stairs or riding the lift moves the window. Each floor's GLB is cut into the published rooms against the whole building's outlines, by the exact slab-to-slab band first, so a floor's own carpet never goes to the floor below. The material a mesh wears is its key plus the variant the interior box asked for (`extras.materialVariant`), so a patterned ceiling and a plain one stay two looks of one entry. A room is drawn only while it is within reach and on the level the player is on. Interiors stay at their real world position **in the same scene**: entering is walking through a door, never a load screen or a swap. The fetch, parse, world-space bake and room cut run in a worker that posts one transferable buffer per floor; the frame wraps buffers and builds rooms under an 8 ms budget. The lift and static interior group stay hidden until prepared. While the floor is still detached, its dim view and every fixed room-light binding compile, and decoded maps upload one at a time between frames. Only then can the band and its prepared static group become visible and solid. The hitch log names the worker, preparation and collider costs separately.
- **Doors**: every Exterior `door` and `balconyDoor` leaf on a parcel with an interior, including the roof-bulkhead leaf. Its stable opening id owns only its named GLB subtree, all materials on one physical leaf share one hinge, and E swings that door 100 degrees without moving another opening. The exact rendered leaf triangles are a kinematic collider that follows the hinge, so a closed leaf stops the player and an open leaf clears the doorway. Main street entrances remain the parcel locations used by venues, quests and NPC schedules. A shell-only parcel keeps every leaf fixed in its visible shell and collider, with no interaction target.
- **Variety**: a building wears one variant of each material, picked from the pattern variants (the ones drawn on the module grid) by its parcel id, so a street mixes them and a rebuild keeps each building's; buildings of the same variant merge into one draw call. The quality tier caps how many patterns from each family participate, from two on low to twelve on ultra.
- **Which buildings are enterable**: one continuous light bar runs inside a separate dark housing up both jambs and over the head of every entrance with an interior, and its entrance fixture is lit. Each bar keeps fitted end caps, uses the uniform strip material and starts beyond the shell's published casing depth, so changing door size cannot repeat a lamp bezel through it or let facade relief cross it. A shell-only parcel keeps its leaf shut, gets no strip and never offers a prompt. A venue's sign follows the simulation rather than the clock: lit while somebody is on duty in there, dark once the place has shut. The minimap marks every enterable venue with a dot in the same two states. Nothing floats: every marker is a fixture on a real surface, and all housings and lenses cost two draw calls for the city.
- **Lifts**: rideable. The cab waits at the ground floor (its lowest stop when the shaft has no ground floor), so a building's door opens on a lift that is there. The interior box publishes the shafts and the GLB carries their doors, so nothing is invented: the published leaves are cut out of the floor band they arrived in and given a slide, and a cab is built inside each shaft. Which triangles belong to which shaft is decided by where they are, so the door plane and the way it faces come off the geometry rather than off a convention. E at a landing calls the cab and opens it, E inside takes the next floor the shaft serves, doors are shut whenever the cab is not standing at that landing, and a moving cab carries whoever is in it, because a character controller is not pushed by a moving collider. The shaft and its cab exist from the building's floor documents before any floor is loaded; each landing's leaves arrive with its floor and are given back when that floor leaves memory.
- **Shell materials**: buildings batch by material key, authored variant and GLB face behavior. An authored two-sided surface remains visible from either side after the runtime replaces its material key; front-only and two-sided surfaces never merge into one draw.
- **Links between buildings**: every bridge, AC tube, tunnel, street wire and rooftop antenna span Connections published, swept from its own path and thickness or cross-section (src/game/links/CONTRACT.md). Aperture links are sliced so each end closes on the exact facade hole. Rooftop spans use their complete catenary path from mast endpoint to mast endpoint and share the wire material bucket. Bridges and tubes are walkable; cables are visual only.
- **Transit**: shelters and signs at every bus stop, and buses, trains and subway vehicles driving their routes at the positions the timetables give in closed form. Both maps draw exactly the routes enabled in the generated Connections document and only their served stops or station entrances. Each station has its street entrances with a lit sign over the way down. Behind them is the station itself: a shaft on its own published footprint with a switchback stair fitted to the depth, the passage at its foot and the platform room it opens into, lit by its own fixtures; a platform already at street level gets a canopy on posts instead (src/game/transit/CONTRACT.md). Vehicles and shelters are bounded instanced draws. At a published stop or platform, E names and boards a service only during its actual dwell and within three metres; simultaneous services open a keyboard-accessible choice. An aboard player is carried at the exact Connections route position and heading with walking, jumping and crouching disabled while mouse look and panels stay active. The HUD names the line and next stop. E leaves only during a dwell at the exact published place, and service termination automatically leaves at the published terminus.
- **Road markings**: paint on the authoritative 3D lane paths of the connections road graph, so it follows the same ramp and deck elevation the cars drive. Every lane paints its own left boundary: broken white where the lane sharing that boundary runs the same way, half of a solid double centre line where it does not. Every segment of `streets.crossings` is painted continental at its junction: 0.45 m bars along the walk, repeated across a 3.6 m corridor, held 0.3 m clear of both kerbs. Paint is paint: it returns whatever the lamps give it and goes dark between them, one draw call for the markings and one for the crossings.
- **Neon**: a venue's own lettered sign comes off its exterior shell (`options.signage`, ../assembly/CONTRACT.md); the game hangs the ad screens on the facade each parcel's street access faces, textured by the materials database's emissive `ad-screen` entries. Brandless screens select the named canonical future-noir variant for their tier (`noir-cyan` or `noir-amber`); named businesses select their `brand:<slug>` variant. Lit window panes sit behind a deterministic share of every window opening, coloured by building type, with per-window brightness and a head-to-sill fall-off baked into vertex colours so the whole skyline is one draw call, and they emit rather than reflect, so they feed the bloom channel without carrying a BRDF. Lamp posts run every 19 m on alternating kerbs of every street, one on each junction's widest corner, none inside a plaza or an alley and a sparse ring around a plaza's edge. Each support bends from its upright post into the route-facing arm and a 1.65 m head on the same axis. The complete head stays outside authored building, tree, highway-support, deck and pedestrian movement volumes. Five fitted 0.16 x 0.28 m diffuser panels face only down toward the route; the 24000 lm, 5000 K light sits beneath their centre and reaches 26 m. Wherever a post does not fit, a 3000 lm pack goes on a real facade turned towards the dark stretch, so every walkable segment in the city, alleys included, is covered end to end by some fixture's own range.
- **Dressing**: seeded trash bags, crates and boxes piled against the walls of alleys, the gaps between facades and service corners, clear of every doorway and walk line (src/game/props/CONTRACT.md). Instanced, so the count does not grow the draw calls.
- **Light**: every one of those emitters is a real light in lumens (src/game/light/CONTRACT.md), clustered on the GPU so the count costs a compute dispatch rather than a BRDF evaluation each. Every fixture sits on something the world actually built: a venue's sign, the fixtures over an entrance, a lamp lens, an ad screen. A building with no sign gets no sign light, so nothing ever lights an empty panel. Interiors are cut into the rooms the interior box published and lit by the fixtures published for them, with the interreflected fill computed from the room's own surfaces rather than dialled.
- **Look**: AgX tone response at one authored exposure, height fog tinted by the light actually filling the air, an environment probe baked from the city at the player (the loading bake in one go; a rebake renders one cube face per frame and convolves on the seventh, so no frame carries the whole city twice), and bloom selected by the emissive channel so tubes and lamp lenses glow and the walls they light do not (src/game/look/CONTRACT.md).
- **Pipeline startup**: the first visible exterior view builds only the programs it draws. Feeding the complete large city to either backend can keep its compiler occupied for minutes. A streamed floor is bounded and prepares while detached at the 70 m load radius, including all stable room-light slots, so approaching it never makes the visible frame link its shaders or batch its map uploads. Fixed light identities keep later camera translation on those pipeline keys.
- **Materials**: every map loads with `flipY` off. The geometry that wears them comes from glTF, whose UVs put v = 0 at the top of the image; the game's own panels are authored the same way. Opaque surfaces use the standard metallic-roughness shader; only a material with published transmission takes the larger physical shader. The material a key resolves to is shared by every mesh of that key and is never edited in place: a hotter emission or a two-sided panel takes a tuned copy. A surface the look is graded against by eye (a lamp lens, an entrance diffuser, a lift's cab light) takes its emissive level outright, so a materials release re-authoring a family's strength changes what the map looks like and never how bright the game runs it; a sign takes a scale on top of the database's own tiering, because that tiering is the point.
- **Sky and the day**: `SkyMesh` driven by the real sun arc, so it rises around 07:30 and sets around 18:30. One key light crosses from a moon at the illuminance a full moon really gives to direct sun at 100000 lux, and the analytic sky is scaled onto the same cd/m2 as everything else, from the authored night skyglow (which is what stops a window being a hole cut out of a night frame) up to real daytime sky luminance. Stars fade out at civil twilight.
- **The day cycle**: the 1:1 clock says which of four states the sky is in (dawn, day, dusk, night) off the sun's elevation, never off the clock face, and one number, `daylight`, is what everything downstream reads. Its inverse switches every light the city built together: lamp lenses, venue signs, ad screens, facade fixtures and the lit window panes go out at sunrise and come back at dusk, and the real point lights are dimmed by the same figure, so what the eye sees and what the BRDF gets never disagree. Exposure moves with it, in stops off the authored night grade and taken from the real illuminance ratio: a sunlit street is about a thousand times a lamp-lit one. An interior keeps its own offset at every hour. A run still starts at night.

## Physics
- Rapier 0.20, fixed 1/60 step. Ground, highway decks and supports, and every building shell are fixed trimeshes built once. A shell collider keeps structural walls, columns, slabs, roofs, glass, rails and solid service objects; window-frame relief, signs, lamps and trim remain visual geometry. The structural surfaces carry their real door and window openings. Each moving Exterior leaf adds its exact local triangles as one position-driven kinematic trimesh at the published hinge, and its collision rotation follows the rendered pivot. Position-only collider merges expand every indexed source first, preserving complete triangle lists. Each lamp post is one thin fixed cylinder, not a mesh. An interior floor band becomes a trimesh when the stream puts it in the scene and stops being one when it takes it out, so what can be walked on is exactly what can be seen.
- A car is a box the player is pushed out of the same way, through whichever side is nearer; a car whose lane the player stands in eases down from 10 m ahead of its nose and holds 1.5 m short of them. Separate Rapier kinematic sensors follow every generated vehicle and visible pedestrian. A contact at 2 m/s or faster interrupts the exact pedestrian and applies the measured direction and speed to a dynamic body.
- Walking crowd members use summed pushback through the character controller, so a person cannot be walked through and a push cannot shove the player through a wall. One impacted person at a time leaves its baked slot and becomes the same full Source body with 15 Rapier parts, 14 spherical joints and 70 kg total mass. It starts at the current baked animation frame, collides with the generated world and is excluded from talk and pushback. An incompatible rig fails closed, and another impact stays under crowd control until the full body slot is free.
- Player: capsule collider driven by `KinematicCharacterController` with autostep (0.42 m, which is what makes curbs and interior stairs walkable) and snap-to-ground. Jump begins only while grounded and standing. Crouching shortens the real collider without moving its feet; releasing C restores the standing collider only when a full capsule query proves the head space is clear.
- During an active transit journey the capsule leaves collision and receives exact route positions; physics steps and moving-collider pushes are suspended. Elevator teleports cannot override that carried position. Disembarkation restores the capsule at the Atlas stop or platform point.
- Nonfatal physical falls are presentation state for the current run. A contact at or above the physics contract's fatal threshold applies the simulation `die` flag only when the exact fallen actor is the active assassination target and its Source ragdoll was accepted.

## People and traffic
- Population is the simulation library's, never invented here. The crowd slice for each walk edge around the player is the authoritative set of people on that pavement (a city-scope slice is a sample of the whole city, so it starves the street in front of the player); every agent it reports is spawned where the simulation says it is and then walks the connections walk graph at 1.4 m/s, holding at signalled crossings until the walk phase. Movement reads each edge's authoritative `path3`, including grade, station access, stairs, passage, platform and building-link edges. The raised sidewalk and access surface adds its 0.12 m curb height; a station stair blends from that surface to its exact lower landing. The parcel crowd slice adds each nearby building's on-duty staff, standing in its lobby.
- A person in the world is a body of the game's own, and the simulation handle it carries is the identity it holds right now. A street handle names a sampled agent for one epoch of that pavement, so every few minutes the same people come back under new handles: each refresh fits the people already out there to the ones the simulation reports now, of their own type and standing nearest to where it puts them, and only an agent nobody can be gets a new person. Whoever is left over retires, keeps walking and leaves the world from more than 60 m back, so nobody is ever seen going out. A building follows the same rule as its rota moves through the day: whoever the simulation has on duty stands at one of the interior's ground-floor work spots, a guest sits on one of its seats (npc.json anchors, in id order, facing as the anchor says), and when the anchors are full a person stands in the lobby. So the number of people on the street is the number the simulation has out there for as long as the session runs, no two of them are ever the same person, and somebody the player has talked to keeps the identity they were given.
- A seated person talks seated and goes back to sitting when the player leaves. Talking instantiates the person's crowd handle, interrupts its routine, shows the identity and weekly routine the simulation returns, and resumes it on close. A street handle answers for its sampling epoch; after that, interaction resolves a live handle from the pavement or lobby slice, widened to streets within 25 m for a walker on an empty stretch and excluding identities already in use. E on a person always opens the panel; where nobody is out on that street it reads as someone passing by.
- Rendering: animation clips are baked once into vertex animation buffers, so the ordinary crowd is 4 draw calls and has no skeleton per person. The mass crowd deliberately keeps the two regular body meshes and downscaled maps; baking all six Source bodies into vertex animation textures would multiply persistent GPU memory and draw calls. Each regular male/female body draw merges the Source body with its eyes, selecting the eye map by a vertex marker; each hair draw merges the hairstyle with the Source eyebrows and uses that gender's own hair map. Every baked frame skins the Source vertex normals with the renderer's bone matrix, applies the instance heading and enters view space, preserving authored smooth surfaces and hard edges through animation. The meshes use instanced buffer geometry rather than an unused identity `instanceMatrix`; every source channel the shader does not read is dropped, so each pipeline stays within the WebGPU minimum of eight vertex buffers and follows the same pose path on WebGPU and the WebGL2 half-float fallback. A person in conversation or one physically fallen person leaves their baked slot only after a full-quality skinned Source model and hairstyle pieces are loaded. Its seeded gender-correct shape is one of all six regular, teen or superhero bodies, and its head style plus optional facial hair are selected from all 32 compatible Source files. Pro animation drives the conversation armature; Rapier drives the fallen armature. Each separately exported hairstyle piece is baked into Head-local geometry. Only the active dialogue shape and one fallen shape may remain resident; changing shape releases unused model geometry, materials and 4K maps.
- Dress: the base characters ship undressed, so the clothes are painted on. A garment map baked at load says which part of the body each vertex belongs to, read off the bones driving it, and each person carries their own skin tone, shirt, trousers, hair colour and where their sleeves and hems end, all decided once from their crowd id. The focused model receives that same garment mask and exact outfit before it replaces the baked slot. Nothing is added to either mesh, so the draw call count does not move.
- Cars drive the connections lane graph at each lane's posted speed along the authoritative 3D `path3`, including every grade breakpoint. At the end of a lane a car takes one of that lane's turn connections, chosen by its own seeded rng, holds at the stop line while that turn is red, then drives the turn's own 3D `via3` curve through the intersection onto the next lane. Elevation and body pitch follow those paths, so a ramp is driven rather than flattened. Cars keep a 7 m following gap on the line they share and spawn into a gap wide enough for one. A car leaves the world past 140 m from the player, or where the lane graph ends with no turn connection. Two instanced draws per model.

## Errors
The whole run either starts or reports why: any failure during startup is caught and shown on the loading panel with its message. There is no partial world.
- `E_MOVEMENT_PATH3`: a walk edge, road lane or turn has no valid authoritative 3D path. The compatibility 2D projection is never used as a fallback.
- `E_HIGHWAY_STRUCTURE`: a published highway path, elevation profile, dimension or support cannot be built exactly. The run refuses without inventing geometry.

## Invariants
- Only generated data is rendered: no placeholder geometry, no invented population, no untextured surface outside the deliberate light emitters.
- A catalog game resumes from its last confirmed revision, and leaving it succeeds only after that next revision is stored.
- A catalog save includes the optional exact timetable journey and quest transportation stage. Boarding, disembarking and automatic termination save both through the normal persistence boundary; leaving and quest saves also capture their current state. A direct preview keeps them in the session only. Restore cross-checks approach, aboard or arrival progress against the exact quest, passenger and follow state. A valid aboard restore also restores its absolute timetable clock, while a stale trip fails closed to waiting.
- A catalog save keeps the simulation replay and NPC continuity state at the same world minute. Named bodies restore with the same npcId, appearance seed, interruption, follow or return route, schedule progress and destination; distant bodies may be virtualized without replacing their identity.
- An explicit cast NPC crouch is saved with its interrupted routine and exact npcId. Release plays the crouch exit and returns that identity over the walk graph to its current schedule. Player C input never triggers NPC crouch.
- Animation coordinator state is reconstructed from restored quest and NPC continuity state. It is not stored as a second source of NPC control truth.
- Interiors are continuous with the street: same scene, real world position, no loading screen and no camera jump.
- Only manifest `interiors` parcels can open a door, register simulation interior support, or fetch an interior floor. Every other manifest parcel remains a closed exterior shell.
- Every mobile world position preserves the Y coordinate published by Connections; movement is never flattened to XZ.
- Highway road, structure, supports, lane paint and collision share the dimensions and elevation supplied by Atlas and Connections.
- The player cannot pass through a building shell and cannot fall through the ground.
- The crowd's draw call count does not grow with the number of people.
- The people out on the street are the people the simulation says are out there, however long the session runs, and no two of them are the same person.
- A material key the database cannot answer renders magenta and is counted in the readout; it never takes the run down, because a world can name a brand whose assets are not on this machine.
